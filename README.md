# NVIDIA Certified Associate: AI Infrastructure and Operations (NCA-AIIO)

## Complete Study Course

This repository contains a comprehensive study course for the **NVIDIA Certified Associate — AI Infrastructure and Operations (NCA-AIIO)** certification exam, organized into four learning modules that mirror the official NVIDIA training curriculum.

## Exam Domain Weights

| Domain                     | Weight | Description                                                                                                                              |
| -------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **AI Infrastructure**      | 40%    | GPU scaling, AI hardware, power & cooling, on-prem vs. cloud, networking, cluster components, DPUs                                       |

## Course Modules

### [Module 1 — AI Fundamentals](Module-1-AI-Fundamentals.md)
The evolution of artificial intelligence, from classical AI to generative AI. Covers AI/ML/DL/Gen AI definitions, real-world industry use cases across automotive, healthcare, finance, retail, manufacturing, and video analytics. Introduces the Transformer model architecture that powers modern AI.

### [Module 2 — Inside an AI-Centric Data Center](Module-2-Inside-AI-Data-Center.md)
A deep dive into the four pillars of modern AI data center infrastructure: Compute (CPU, GPU, DPU), Networking (InfiniBand, NVLink, NVSwitch, Ethernet), Storage (parallel file systems, GPUDirect Storage), and Support Infrastructure (power, cooling, security). Covers GPU evolution, CPU vs GPU architecture, PUE metrics, and NVIDIA-Certified Server design.

### [Module 3 — NVIDIA Technology Stack](Module-3-NVIDIA-Technology-Stack.md)
The complete NVIDIA hardware and software ecosystem for AI. Covers GPU architectures from Volta to Blackwell, DGX/HGX/MGX systems, the CUDA programming model, core libraries (cuDNN, cuBLAS, NCCL, TensorRT), deployment tools (Triton Inference Server, NIM), NGC catalog, NVIDIA AI Enterprise, and the NeMo framework for LLMs.

### [Module 4 — AI Workflows and Operations](Module-4-AI-Workflows-and-Operations.md)
The end-to-end AI lifecycle from data preparation through deployment and monitoring. Covers the AI/ML pipeline, training at scale, inference optimization, NVIDIA deployment tools, and AI operations including DCGM monitoring, GPU Operator, Kubernetes GPU scheduling, Slurm workload management, MIG partitioning, and vGPU virtualization.

## How to Use This Course

1. **Sequential Study**: Work through Modules 1–4 in order. Each module builds on concepts from the previous one.
2. **Focused Review**: Use the domain weight table above to prioritize your study time — AI Infrastructure (40%) and Essential AI Knowledge (38%) together account for 78% of the exam.
3. **Key Terms**: Each module highlights critical NVIDIA-specific terminology and product names that appear on the exam.
4. **Practice**: After completing all modules, test your knowledge using NVIDIA's official practice resources.
